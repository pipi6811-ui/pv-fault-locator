# tools

## trace.py — 把掃描的串併圖描成向量

紙本掃描直接拿來用，破片定位一放大就糊，而定位本來就要放大才點得準。
這支程式把掃描圖描成 SVG：放多大都銳利，檔案也比原圖小。

### 用法

```bash
python3 -m venv venv && ./venv/bin/pip install pillow numpy
./venv/bin/python tools/trace.py 原圖.jpg 輸出.svg [放大倍率] [簡化容忍度] [雜點門檻]
```

預設 `2.0 0.9 12`。實務上 **`2.0 1.3 60`** 是甜蜜點 ——
1284×1412 的掃描圖會得到約 129 KB 的 SVG，跟 335 KB 的精細版肉眼無差。

```bash
./venv/bin/python tools/trace.py 三民國小.jpg 三民國小.svg 2.0 1.3 60
```

### 做法

1. **局部門檻二值化** — 掃描紙張明暗不均，固定門檻會把淡線吃掉
2. **去雜點** — 掃描的髒污與 JPEG 雜訊
3. **crack following 取輪廓** — 沿墨與紙的交界走，數學上保證閉合
4. **Douglas-Peucker 簡化** — 控制檔案大小

> 第一版用 marching squares，鞍點與 visited 的判斷有漏，輪廓會中途斷掉再被
> `Z` 硬接起來，在圖上填出一塊不存在的黑色三角形。改走裂縫之後解決，
> 順便快了 8 倍。

### 兩個會踩到的坑

**顏色不能用 `#rrggbb`。** 程式輸出的是 `white` 與 `rgb(17,17,17)`，
因為這個 SVG 會變成 `data:` URI，而 **`#` 在 URI 裡是片段起點**，
SVG 會從那裡被整個截斷，圖完全讀不出來。

**產生出來的圖放進 App 的方式**：丟到 NAS 的 `98 破片管理/_串併圖/`，
檔名就是案場名稱（例如 `三民國小.svg`），App 的設定頁第 11 區按
「從 NAS 取得串併圖」就會抓下來並快取，不必改程式。
