怎麼訓練自己的模型

1. 電腦開 teachablemachine.withgoogle.com → Get Started → Image Project → Standard image model

2. 每個標的物開一個 Class，名稱打中文，和檢查項目文字一致，把檔案庫的照片拖進去。
每類至少 50 張，多角度、晴天陰天都要有。

3. 按 Train Model，跑完後 Export Model → TensorFlow.js → Upload my model → 複製網址

4. 貼到上面 → 載入模型。
