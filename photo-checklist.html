    怎麼訓練自己的模型

    1. 電腦開 teachablemachine.withgoogle.com → Get Started → Image Project → Standard image model

    2. 每個標的物開一個 Class，名稱打中文（監控箱、太陽能板…），把你檔案庫的照片拖進去。
    每類至少 50 張，多角度、晴天陰天都要有，效果差很多。

    3. 按 Train Model（跑幾分鐘，別關分頁）

    4. Export Model → 選 TensorFlow.js → Upload my model → 複製它給的那串網址

    5. 貼到上面「模型網址」→ 按載入模型。
